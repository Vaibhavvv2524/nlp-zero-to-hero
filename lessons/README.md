# Early NLP lessons

These are the generic warm-up exercises from the beginning of the course and
are unrelated to the Hindi assignment.

- `preprocessing.py` - cleaning, tokenization, stopwords, stemming, lemmatization
- `train.py` - a small TF-IDF + logistic-regression text classifier

Run them directly from the repository root, for example:

```bash
python lessons/preprocessing.py
python lessons/train.py
```
